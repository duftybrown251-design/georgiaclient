# Kia Ora Client Hub - Static Vercel Demo

This version is intentionally static so it can be deployed to Vercel without a Node/serverless function.

Open `index.html` locally or deploy the folder to Vercel. Client/task/note demo changes are stored in the browser's localStorage.

Server-side authentication, Supabase, Gmail/Outlook, and calendar integrations can be added in a later stage without changing the visual layout.
